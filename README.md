# Clínica Kossmann

Site demonstrativo responsivo feito com HTML, CSS e JavaScript, sem dependências ou etapa de compilação.

## Visualizar

Abra `index.html` no navegador. As fontes do Google Fonts precisam de conexão com a internet; há fontes alternativas locais.

## Estrutura

- `index.html`: conteúdo e estrutura da página.
- `css/style.css`: estilos e adaptação para dispositivos móveis.
- `js/main.js`: menu, perguntas frequentes, animações e links do WhatsApp.
- `assets/images/`: pasta para imagens.
- `assets/icons/`: pasta para ícones.

## Enviar ao repositório

Se estiver usando o ZIP, extraia-o primeiro. Envie o conteúdo desta pasta para a raiz do repositório, incluindo `index.html`, `css`, `js`, `assets`, este README e `.gitignore`. Não envie apenas o arquivo ZIP.

## Personalizar

Configure `WHATSAPP_NUMBER` em `js/main.js` com código do país, DDD e número, usando apenas dígitos. Atualmente o número está vazio e os links abrem o WhatsApp sem destinatário definido.

Substitua os campos demonstrativos em `index.html` e as respostas do FAQ em `js/main.js` pelas informações confirmadas. Adicione as imagens à pasta `assets/images/` e referencie-as no HTML.

Este projeto não é o site oficial da clínica. Fotos, endereço, contatos, registros profissionais e depoimentos ainda precisam ser preenchidos.
